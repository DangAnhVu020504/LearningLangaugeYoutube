Kiểm tra xem Angular có đang chạy không

Đang kiểm tra...

📋 Hướng dẫn Debug

  1. Mở Angular: http://localhost:4200
  2. Nhấn F12 để mở DevTools
  3. Xem tab Console - Có lỗi màu đỏ không?
  4. Xem tab Network - File nào bị lỗi 404?
  5. Xem tab Elements - Có thẻ <app-root> không?

Các lỗi thường gặp:

  • "YT is not defined" → Đợi YouTube API load (vài giây)
  • "Cannot find module" → Chạy: npm install
  • "404 Not Found" → Restart Angular
  • Trang trắng hoàn toàn → Xem Console có lỗi gì

Giải pháp nhanh:

  • Hard Reload: Ctrl + Shift + R
  • Xóa cache: DevTools → Network → Disable cache
  • Thử trình duyệt khác: Chrome, Firefox, Edge
